# Zern
TrollStore iOS crash‑log viewer, parser and filter tool

## Supported
iOS 15.0+ (arm64) for TrollStore.

## Features
‑ Browse system `.ips` crash reports from CrashReporter and DiagnosticReports.
‑ Auto‑parse crash type: Panic, Jetsam, CPU‑Kill, watchdog reset, application exception and more.
‑ Multiple filters: filter by app / system logs, time range, crash category.
‑ Preview raw crash log text inside‑app.
‑ Export log files, open log path in Filza if installed.

## Download
Go to [Releases](../../releases) to get Zern.ipa and install via TrollStore.

> Source code is available in this repository for developers.

## Build note
Compile with system `/usr/bin/clang`.
